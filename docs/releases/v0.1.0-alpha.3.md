围绕朋友开黑补齐加入说明、连接诊断、地图分享、Steam 身份好友名单、官方游戏更新和定时维护。Python 版本为 `0.1.0a3`。

- [Linux x86_64 可执行包](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.3/l4d2-server-cli-v0.1.0-alpha.3-linux-x86_64.tar.gz)
- [SHA256 校验文件](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.3/l4d2-server-cli-v0.1.0-alpha.3-linux-x86_64.sha256)

校验解压后运行 `sudo bash ./install.sh`，版本应为 `0.1.0a3`。CLI 升级保留游戏和房间；游戏更新由 `room update` 单独执行。要求 Linux x86_64、glibc 2.31+；游戏维护需要 systemd 和游戏运行依赖。

## 新增功能

- `room invite` 生成控制台/Steam 组大厅加入说明，使用运行端口，提示待生效配置和好友名单。
- `room connect-check` 与跨平台 `network probe` 展示服务/UDP/查询证据和下一步；真实加入单独验收。
- `map share` 展开 Workshop 合集/声明依赖，保留登记分包，生成订阅链接；无 API key、缺失或隐藏条目标记不完整。
- `access configure/status` 使用内置 SourceMod 插件按已验证 SteamID64 控制好友名单，核对策略摘要和插件运行回执，管理员没有自动绕过权限。
- `room update` 对停止的共享游戏目录更新官方内容，备份配置/插件，检查中断记录与运行依赖，完成后单独启动。
- `schedule add/list/run/remove` 提供 systemd 定时备份与健康检查、最近结果、受限备份保留与移除。
- 常用房间/资源和新增命令显示中文，Windows 输出 UTF-8；保留 JSON。可选 Web 通用命令复用新增能力。
- CI 以固定摘要校验官方 SDK 后编译访问插件；发布刷新草稿查询并等待创建结果。

## 验证与限制

自动回归覆盖邀请端口、依赖图/循环/缺失、名单摘要/回执、更新失败阻止启动、任务定时/保留/失败记录。发布流程另检查 Linux/Windows、Python 分发、前端一致性、Linux 可执行包和 glibc 2.31 入口。

没有可用的授权实机和玩家，因此本版新增的真实整服更新、systemd 定时执行、名单内外加入、重连/换图和持续多人对局仍待验收。插件编译与运行回执不等于这些验证通过。框架故障、插件卸载或绕过 CLI 启动时不能保证访问限制。

房名仍用 ASCII；原生入场密码仍不支持，Steam 组不是严格白名单。来源可能漏写依赖，清单不证明朋友已下载。定时备份不含地图主体/旧游戏二进制；更新不自动回滚旧版本，不在有人游玩时自动停服。健康检查只记录异常，不自动重启或通知。
