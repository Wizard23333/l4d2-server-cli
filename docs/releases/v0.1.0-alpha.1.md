# v0.1.0-alpha.1（预览版）

L4D2 Server CLI首个开源预览版，Python包版本 `0.1.0a1`。管理一个使用官方地图的Linux专用服务器实例。

## 功能

- 官方服务端安装、来源网络预检、已有SteamCMD及本地包备用路径。
- 原生密码/Steam Guard首次登录、私有缓存核验和非匿名下载；二维码为可选后端，授权/下载全链仍待测。
- ASCII房间名、IPv4、端口、官方地图、coop/versus、合作难度、RCON和开机启动配置。
- public/group两种预设、短Steam组ID、配置向导、保存与重启分离。
- start/stop/restart/status/logs/doctor、幂等操作、就绪与进程归属验证。

## 安装

Release附件提供 [Linux x86_64可执行目录包](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.1/l4d2-server-cli-v0.1.0-alpha.1-linux-x86_64.tar.gz) 和 [SHA256校验文件](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.1/l4d2-server-cli-v0.1.0-alpha.1-linux-x86_64.sha256)。包内置CPython3.12.15运行时，无需安装系统Python、venv或pip；要求Linux x86_64、glibc2.31+，游戏管理还需要运行中的systemd及游戏依赖。

下载两个附件后校验、解压并保留整个目录（包括 `_internal/`）。安装说明见 [README](../../README.md)和 [可执行包说明](../executable-package.md)。源代码可通过本页自动提供的源码归档或仓库获取。

## 验证范围

Linux可执行包已在Ubuntu20.04/glibc2.31验证独立运行、版本与帮助、已安装房间状态、配置/启停的只读计划及经HTTP代理的官方SteamCMD工具下载。此前的服务端完整安装和生命周期验证继续适用于相同运行代码；本次包检查没有重新安装或重启游戏。HTTP代理下载成功不代表Steam内容协议或任意服务器网络均可用。

## 已知限制

本版本是alpha预览版。Ubuntu20.04已有实机使用记录，其他发行版的完整流程、严格离线游戏包、二维码批准/下载、versus及长时间/多玩家行为尚未全部验证。

房间名称仅ASCII，不支持非空入场密码；Steam账号密码和RCON密码保留。Steam组优先不等于严格成员白名单。

不包含三方图、Workshop、MOD、在线切图、多实例、Web面板或自动更新。

源码为MIT许可；可执行包中的Python及运行库保留各自许可证。SteamCMD、游戏内容和可选二维码后端不随包分发。
