# v0.1.0-alpha.1（候选）

L4D2 Server CLI首个开源预览版，Python包版本 `0.1.0a1`。管理一个使用官方地图的Linux专用服务器实例。

## 功能

- 官方服务端安装、来源网络预检、已有SteamCMD及本地包备用路径。
- 原生密码/Steam Guard首次登录、私有缓存核验和非匿名下载；二维码为可选后端，授权/下载全链仍待测。
- ASCII房间名、IPv4、端口、官方地图、coop/versus、合作难度、RCON和开机启动配置。
- public/group两种预设、短Steam组ID、配置向导、保存与重启分离。
- start/stop/restart/status/logs/doctor、幂等操作、就绪与进程归属验证。

## 安装

提供Linux x86_64可执行目录包（内置Python运行时）、Python wheel与源码包，均附校验和。安装说明见 [README](../../README.md)和 [可执行包说明](../executable-package.md)。当前候选仅本地提供，尚未发布GitHub。

## 已知限制

本版本是alpha预览版。Ubuntu20.04已有实机使用记录，其他发行版的完整流程、严格离线游戏包、二维码批准/下载、versus及长时间/多玩家行为尚未全部验证。

房间名称仅ASCII，不支持非空入场密码；Steam账号密码和RCON密码保留。Steam组优先不等于严格成员白名单。

不包含三方图、Workshop、MOD、在线切图、多实例、Web面板或自动更新。

源码为MIT许可；可执行包中的Python及运行库保留各自许可证。SteamCMD、游戏内容和可选二维码后端不随包分发。
