# v0.1.0-alpha.2（预览版）

本版将多房间、地图/插件、备份、可选 Web 和 Agent Skill 纳入同一 CLI 发行包，并新增中文首次开服引导。Python 版本为 `0.1.0a2`，与仅包含单实例官方图的 alpha.1 区分。

## 下载与开始

- [Linux x86_64 可执行包](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.2/l4d2-server-cli-v0.1.0-alpha.2-linux-x86_64.tar.gz)
- [SHA256 校验文件](https://github.com/Wizard23333/l4d2-server-cli/releases/download/v0.1.0-alpha.2/l4d2-server-cli-v0.1.0-alpha.2-linux-x86_64.sha256)
- [安装与支持范围](../../README.md) / [首次开服教程](../getting-started.md)

内置 Python，要求 Linux x86_64、glibc 2.31+，游戏运维需要运行中的 systemd 和游戏的 32 位依赖。校验、解压后执行 `sudo bash ./install.sh` 注册 CLI，再执行 `sudo l4d2 setup`。

## 主要变化

- `setup` 中文引导：选择官方战役、难度、端口、加入方式和来源，先检查与预览，再安装、配置、按需启动，输出加入说明。支持 `--dry-run`、`--no-start`、`--yes` 和 `--json`；保留失败阶段和已完成步骤，保护已有运行中的 main。
- 多房间与旧服接管；Workshop/GameMaps 搜索解析、VPK 导入校验与地图启停/切换；SourceMod 框架、插件、管理员和 RCON。
- 独立后台任务、Manifest/ZIP 资源传输、私有配置/插件状态备份恢复、存储和受控修复。
- 可选 Web 面板复用同一 CLI，提供预览后执行和后台任务；统一 Agent Skill 可在 Windows/Linux/macOS 本地安装到常用工具。
- 全局 CLI 安装器、中文诊断/网络/状态输出、SteamCMD 可信 CDN 回退及原生包网络探测修复。
- 发布检查增加前端重建一致性和引导入口检查；源码、Python 包与原生包使用同一版本。

## 升级

从 alpha.1 升级时，在已校验的新包目录执行安装器。保留旧 CLI 安装，切换全局命令；不更新或重装游戏、不启停现有房间。已有服务器无需重新执行 `setup`。详见 [升级说明](../getting-started.md#5-从-alpha1-升级)。

## 验证与边界

发布工作流对当前提交执行 Linux/Windows Python 回归、前端类型和构建一致性、源码与 Python 分发检查、Linux 原生包摘要/内容检查、解压入口和网络探测检查。原生包还检查 glibc 2.31 入口兼容性；这些自动检查不下载完整游戏或启动真实房间。

此前已有 Ubuntu 20.04 安装、生命周期、地图/插件与 Web 的实机记录。本版新增的完整引导仍需要更多干净主机及外网玩家参与验收；本次发布不宣称已完成全量新装、跨机器恢复或完整多人战役验证。

房名仍限制 ASCII，不支持非空入场密码；Steam 组优先不是严格白名单。本机就绪不等于公网能加入。GameMaps 可能受源站保护，需浏览器下载后导入；多 Part 在线组合、跨机器恢复、实验扫码、严格离线和长期多人运行继续保留测试边界。游戏自动更新、Windows 原生服务端、ARM 和无 systemd 容器不在本版范围。

源码为 MIT；游戏、SteamCMD、认证缓存和服务器秘密不随包分发。报告问题请提供确切版本、环境、失败阶段与脱敏输出。
